CAMERA AUTO UPLOAD — FTP CAMERA SETUP HELP
Version 0.5.1 beta
Verified camera profiles: 48
Last reviewed: October 2026

WHAT THIS APP DOES
Camera -> FTP receiver on Android phone -> save JPEG on phone -> optional Flickr upload over cellular.

COMMON FTP SETTINGS
Protocol: FTP (plain FTP; do not choose FTPS or SFTP)
Server/Host: use the phone IP displayed in the app
Port: 2121 (some cameras display this as 02121)
User: nikon
Password: use the value shown in Settings > Advanced FTP
Passive/PASV mode: ON when available
Destination folder: Root/Home folder
Recommended transfer file: JPEG only
Automatic transfer: ON
Delete after transfer: OFF

IMPORTANT
The phone IP can change when you change from the camera's Wi-Fi to the phone hotspot or another network. Always use the current IP shown by the app.
For Nikon direct-access-point models, the CAMERA creates the Wi-Fi and the phone joins it.
For Canon, Sony, and Fujifilm profiles, the PHONE hotspot is the easiest field workflow and the camera joins the phone.
Older Nikon/Canon bodies and Fujifilm X-H2/X-H2S require the listed wireless transmitter accessory.

NIKON — BUILT-IN WIRELESS FTP
============================================================
Supported:
- Nikon Z9
- Nikon Z8
- Nikon Z6III
- Nikon Z5II
- Nikon Zf
- Nikon Z50II
- Nikon ZR

Setup:
1. Network menu > Connect to FTP server > Network settings > Create profile > Connection wizard.
2. Choose Direct connection / Wi-Fi access point mode.
3. The camera shows its SSID and password. On Android, join that camera Wi-Fi.
4. Back on the camera, choose FTP.
5. Enter port 2121.
6. Choose Enter user ID.
7. User = nikon.
8. Password = the app's Advanced FTP password.
9. Destination = Home/root folder.
10. Connect. The FTP profile should show connected/green.
11. Connect to FTP server > Options > Auto upload = ON.
12. If shooting RAW+JPEG, choose JPEG-only transfer when available.
13. Keep Delete after upload OFF.

CANON — PHONE HOTSPOT + FTP
============================================================
Supported with built-in Wi-Fi FTP:
- Canon EOS R1
- Canon EOS R5 Mark II
- Canon EOS R3
- Canon EOS R5
- Canon EOS R6 Mark III
- Canon EOS R6 Mark II
- Canon EOS R6 V
- Canon EOS R6

Wireless accessory profiles:
- Canon EOS-1D X Mark III + WFT-E9
- Canon EOS-1D X Mark II + WFT-E8

Setup:
1. Android Settings > Mobile Hotspot > ON.
2. Connect the Canon camera to that hotspot.
3. Communication functions / Wireless features > Transfer images to FTP server.
4. Create/add a connection.
5. Choose FTP, not FTPS.
6. Server address = phone IP shown by the app.
7. Port = 2121. If the Canon screen uses five digits, enter 02121.
8. Passive mode = Enable.
9. Login method = user/password.
10. User = nikon.
11. Password = app Advanced FTP password.
12. Target folder = Root folder.
13. FTP transfer settings > Automatic transfer = Enable.
14. Images to transfer = JPEG when shooting RAW+JPEG.

FUJIFILM — PHONE HOTSPOT + FTP
============================================================
Supported with built-in FTP:
- Fujifilm GFX100 II
- Fujifilm GFX100S II

Requires FT-XH:
- Fujifilm X-H2 + FT-XH
- Fujifilm X-H2S + FT-XH

Setup:
1. Android Mobile Hotspot = ON.
2. Connect the Fujifilm camera/file transmitter to that hotspot.
3. Network/USB Setting > Create/Edit Connection Setting > Create Using Wizard > FTP Transfer.
4. Choose Wireless LAN.
5. Configure the phone hotspot network.
6. Create FTP server settings.
7. FTP server type = FTP.
8. Server address = phone IP shown by the app.
9. Port = 2121.
10. Proxy = Disable.
11. PASV = Enable.
12. User Name & Password = nikon + app Advanced FTP password.
13. Destination = Root Folder.
14. FTP Optional Setting > Auto Image Transfer Order = ON.
15. Use JPEG for this app/Flickr workflow.

============================================================
TROUBLESHOOTING
============================================================
Camera cannot connect:
- Confirm the app receiver is running.
- Confirm the camera and phone are on the same Wi-Fi network.
- Re-check the phone IP shown in the app.
- Port must be 2121.
- User must be nikon.
- Re-enter the FTP password exactly.
- Use plain FTP, not FTPS/SFTP.
- Enable Passive/PASV when available.
- Temporarily disable VPNs.
- On Android, allow the app to run in the background and exclude it from aggressive battery optimization if transfers stop when the screen is off.

Camera connects but no photo arrives:
- Turn Automatic transfer / Auto FTP Transfer / Auto upload ON.
- Set the camera to send JPEG.
- If shooting RAW+JPEG, choose JPEG only.
- Make sure the camera is actually connected to the FTP profile while shooting.

Phone receives photos but Flickr does not:
- Camera-to-phone FTP and Flickr are separate.
- Leave Flickr Upload enabled in the app.
- Make sure mobile data is on.
- The app should report cellular/5G-LTE ready.
- Pending uploads stay on the phone and retry later.

SECURITY
The app intentionally uses a local FTP server on the camera/phone network. Do not expose port 2121 to the public internet or forward it through a router. Use a strong FTP password.
